# pycauset.spacetime

The `pycauset.spacetime` module contains classes representing different spacetime manifolds.

## Classes

*   [[pycauset.CausalSpacetime]]: The abstract base class for all spacetimes.
*   [[pycauset.spacetime.MinkowskiDiamond]]: A causal diamond in flat space.
*   [[pycauset.spacetime.MinkowskiCylinder]]: Flat space with periodic spatial boundaries.
*   [[pycauset.spacetime.MinkowskiBox]]: A rectangular block in flat space.
*   [[pycauset.spacetime.RestrictedSpacetime]]: Restrict a spacetime to a subregion.
*   [[pycauset.spacetime.TransformedSpacetime]]: Apply a coordinate transform.
*   [[pycauset.spacetime.ConformalSpacetime]]: Rescale the metric by a conformal factor.
*   [[pycauset.spacetime.PeriodicSpacetime]]: Identify spacelike axes periodically.
