# pycauset.spacetime

Regions of spacetime to sprinkle causal sets into.

*   [[docs/classes/spacetime/pycauset.spacetime.MinkowskiDiamond.md|MinkowskiDiamond]]: the
    causal diamond in $d$-dimensional Minkowski space.

R1 offers the Minkowski diamond; the rest of the spacetime library (cylinders, boxes,
de Sitter, FLRW, Schwarzschild, custom spacetimes) is parked in `experimental/physics`.
