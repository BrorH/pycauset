# pycauset.load_matrix

```python
pycauset.load_matrix(path)
```

Loads a matrix or vector from a `.pycauset` file. Alias of [[docs/functions/pycauset.load.md|pycauset.load]].

## Parameters

*   **path** (str or Path): Path to the `.pycauset` file.

## Returns

The loaded PyCauset matrix or vector.
