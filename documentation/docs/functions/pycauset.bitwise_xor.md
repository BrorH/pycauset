# pycauset.bitwise_xor

```python
pycauset.bitwise_xor(a, b)
```

Elementwise bitwise XOR of two bit matrices or bit vectors.

## Parameters

*   **a** (matrix or vector): First operand.
*   **b** (matrix or vector): Second operand.

## Returns

A bit matrix or bit vector (`DenseBitMatrix` / `BitVector`).
