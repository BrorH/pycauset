# pycauset.bitwise_or

```python
pycauset.bitwise_or(a, b)
```

Elementwise bitwise OR of two bit matrices or bit vectors.

## Parameters

*   **a** (matrix or vector): First operand.
*   **b** (matrix or vector): Second operand.

## Returns

A bit matrix or bit vector (`DenseBitMatrix` / `BitVector`).
