# pycauset.load_npy

```python
pycauset.load_npy(path)
```

Loads a NumPy `.npy` file into a PyCauset matrix or vector.

## Parameters

*   **path** (str or Path): Path to the `.npy` file.

## Returns

A PyCauset matrix (2D array) or vector (1D array).
